# Trường điện từ · Ôn thi lý thuyết

Ứng dụng web tĩnh ôn trắc nghiệm môn **Trường điện từ** (6 chương, 180 câu hỏi), giao diện tiếng Việt, chạy hoàn toàn offline.

**Bản online:** https://vtt132109.github.io/tdt/

## Cấu trúc

- `public/` — nội dung website được triển khai lên GitHub Pages.
- `.github/workflows/deploy.yml` — workflow tự động deploy mỗi khi push lên nhánh `main`.

## Chạy cục bộ

Mở `public/index.html` bằng Chrome, Edge hoặc Firefox. Không cần build, backend hay kết nối Internet.

Chi tiết về nội dung, tính năng và cách sử dụng xem tại [`public/README.md`](public/README.md).
